## ⚡ Quick Start

1. **Clone the Hub**
   ```bash
   git clone https://github.com/RivanZamzent/MRZproject.git
   ```
2. **Launch any Module**
   - Simply open `index.html` within any subdirectory.
   - For `ProjectUTS_WebPrograming`, ensure your XAMPP server is running and the database is imported from `setup_database.sql`.
